# Steg 138: vakta på databasen og serverens tall

Dette må du gjøre selv, fordi det krever root på serveren og telefonen din. Det tar 5 minutter.

## 1. Installer ntfy-appen

Den er gratis og krever ingen konto. Hent «ntfy» i Google Play eller App Store.

## 2. Sett opp vakta på spillets server

Logg inn på `ubuntu-8gb-hel1-1` (89.167.24.148) som root, og kjør:

```
curl -fsSL https://raw.githubusercontent.com/average01101010/FishyBusiness-/ccr-5e1ba2f4-pusvyd/tools/server/vakt/setup.sh | bash
```

Til slutt skriver den ut et emne som ser omtrent slik ut: `dsb-vakt-3f9a…`. I ntfy-appen trykker du «+» og skriver inn emnet. Hold det for deg selv, for alle som kjenner det, kan lese varslene.

Når det er gjort, kommer meldingen «Det Store Blå: vakta er satt opp» på telefonen.

## 3. Tallene fra serveren (som Laksebaronens)

Telleren for forespørsler per time krever at Caddy får den nye Caddyfile. Kjør hele oppsettet på nytt. Det er trygt å kjøre flere ganger, og en Caddyfile som ikke holder, blir ikke tatt i bruk:

```
curl -fsSL https://raw.githubusercontent.com/average01101010/FishyBusiness-/ccr-5e1ba2f4-pusvyd/tools/server/setup.sh | bash -s detstorebla.no
```

(Det kjører også vakta fra punkt 2, så har du gjort dette, kan du hoppe over punkt 2. Emnet skrives da ut her.)

Når du vil se tallene, kjører du dette og limer inn det som kommer ut i en økt:

```
curl -fsSL https://raw.githubusercontent.com/average01101010/FishyBusiness-/ccr-5e1ba2f4-pusvyd/tools/server/status.sh | bash
```

Forespørslene per time dukker opp etter et par timer, fordi vakta skriver telleren én gang i timen.

## 4. Statussiden til Supabase

Gå til status.supabase.com → «Subscribe to updates» → e-post. Da får du vite når feilen er hos dem.
