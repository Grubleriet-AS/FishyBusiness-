# Steg 133 DP3-5: ryddingen av Driftsplan 3, Håndboka og patchnoten (16.11.2026)

- **Håndboka**, hvor som helst: åpne Håndboka-appen og søk «driftsplan». Kortet skal si to valg (et sted, en ring i kartplotteren, og et redskap fra det som er om bord), så Start, og at planen finner hjem, mottak, vær og rytme selv. Det samme på engelsk.
- **Mannskap-siden**: kortet «Driftsplan» skal si at du velger hvor og med hva båten fisker, og at planen finner resten.
- **Patchnotes** («Den nye driftsplanen: sted og redskap»): fire linjer, med havbåtene (ringen på 8 nm og søket) etter linja om søket med ekkoloddet.
- **Driftsplan-siden og ringen i kartplotteren** skal se ut og virke som før steget (bare ubrukt kode og CSS er tatt ut).
