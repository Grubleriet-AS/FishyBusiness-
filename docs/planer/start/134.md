# Steg 134 RANK1: Ranking-systemet, planen (fartstida som nivå og xp, ferdighetene ved siden av)

**Ferdig når:**
1. `docs/planer/rank1.md` finnes og har: hva som er i spillet i dag (fartstida i `core/09e-fartstid.js`, egenskapene og ferdighetene til mannskapet i `core/04-crew.js` og `core/14-crewlife.js`, hvordan spilleren leses i `plan3Reader`), hva som bygges (nivå, xp og spillerens egne ferdigheter), fasene som steg med filer og tester, og hva som ikke bygges.
2. Planen er sjekket mot engasjementsreglene i `CLAUDE.md` og `docs/engasjement.md`, punkt for punkt: aldri til salgs (ingen haill eller kroner gir nivå, xp eller ferdighet), starter ikke på null, ingen straff for fravær, og hva topplista viser. Hvert punkt har ett svar i planen.
3. Valgene bare Jonas kan ta, står i planen med A/B/C og én anbefaling, og er stilt til ham med spørsmålsverktøyet (en økt han har startet) eller står under «Valg som venter på Jonas» i køen (rutinen).
4. Ingenting i `src/` er endret. Fasene er nye rader i køen under lanseringslinja, med `venter på klarsignal`.

**Les:** `docs/planer/driftsplan-3.md` («Etter dette, eget steg» og «Ranking-systemet (steg 134)», rundt linje 95–97), `src/js/core/09e-fartstid.js` (hele, den er kort), `grep -n "skill\|ferd\|exp" src/js/core/04-crew.js src/js/core/14-crewlife.js`, `grep -n "plan3Reader" -A6 src/js/core/06k-plan3.js`, `docs/engasjement.md`, og skillen `/planlegg` (`.claude/skills/planlegg/SKILL.md`).

Man er tross alt helt fersk på havet. På den måten vil også egenskapene forme seg etter hva spilleren faktisk bruker slags redskaper». Fartstida er i dag «status only, it opens nothing»; det endres.
