## Ferdig når

1. Tallene under står i planfila under «Avlesningen», for 1.12 og for 7.12, bare som summer (aldri enkeltspillere).
2. Pakkens kjøp per døgn, og hvor mange av kjøperne som ikke hadde betalt før.
3. Sjøværspakken og 3-døgnsvarene (`trim_72`, `skip_72`) per døgn uka før og under tilbudet (kannibalisering), og samlet salg per døgn mot 1 650–2 100 kr de tre døgnene før.
4. Gaven: hvor mange leveringer med `data ? 'bw'` som er delt ut (`done_at`), og hvor mange av mottakerne som kjøpte Turbotrim innen sju døgn; trykkene på «Se pakken» (`shop_view` med `pg` `bw_rc`).
5. Andelen betalinger som løp ut i perioden mot én av fire før, og én setning til Jonas om hva tallene sier om neste tilbud.

Kilden er `purchases`, `grants` og `events` i produksjonen (Supabase-koblingen i en økt med Jonas). Rydding samtidig, med Jonas' ja: `update products set active = false where id = 'pakke_blackweek'` og `drop trigger bw_gift on public.grants`.
